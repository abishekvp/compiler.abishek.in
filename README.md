# Web Compiler Studio — `compiler.abishek.in`

A professional, fullscreen, browser-based live HTML, CSS, and JavaScript compiler & IDE:
- **Interactive Multi-Pane Editor:** HTML, CSS, and ES6+ JS with line numbers, code folding/wrap, and auto-indent.
- **Live Sandboxed Execution:** High-performance sandboxed iframe preview with debounced auto-reload and Ctrl+Enter manual run.
- **Interactive Dev Console:** Intercepts `console.log`, `warn`, `error`, `info`, and runtime error traces with clear & filter capabilities.
- **External CDN Manager:** 1-click injection of Tailwind CSS 3, Bootstrap 5.3, React 18, Vue 3, Three.js, GSAP, Chart.js, jQuery, and custom URLs.
- **Starter Templates:** Instant playgrounds for Canvas Matrix animations, 3D CSS Cubes, Tailwind dashboards, Glassmorphism calculators, and Three.js 3D scenes.
- **Responsive Device Simulator:** Switch viewport sizes (100% Responsive, 768px Tablet, 375px Mobile).
- **Export & Share:** Export standalone single HTML bundles, download multi-file project archives, or share projects via encoded URL hashes.
